# Judge rubric for the Hello agent

Score each reply from 1 (bad) to 5 (excellent) on each criterion.

| Criterion | 5 means… | 1 means… |
|-----------|----------|----------|
| **Correct** | Right name, right language, right greeting word for the case | Wrong person or wrong language |
| **Grounded** | Uses only facts from tools/skills (city, time of day); nothing made up | Invents facts (a city, a role, a greeting word not in the table) |
| **Follows format** | Matches the greeting-etiquette template and the sign-off rule | Ignores the template |
| **Tone** | Warm and short; formal when asked | Rude, long-winded, or wrong formality |

A case **passes** if every criterion scores 4 or 5.
